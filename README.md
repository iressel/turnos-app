# Turnos App

Plataforma web responsive de reservas para profesionales independientes (coaching, tarot, astrología, reiki y más). Los profesionales gestionan agendas, servicios y cobros; sus clientes reservan y pagan online.

**Estado:** planificación. Las etapas y tareas están en [TAREAS.md](TAREAS.md) y se van a gestionar en un tablero de Trello.

**Stack previsto:** .NET 10 con DDD · ASP.NET Core Razor Pages + htmx + Alpine.js · PostgreSQL · Mercado Pago · hosting en SmarterASP.NET.
